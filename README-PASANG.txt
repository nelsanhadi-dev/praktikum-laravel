SIM-SURAT - Tailwind Murni + Vite

1. Backup project / pastikan Git bersih.
2. Copy folder resources dari paket ini ke:
   C:\xampp\htdocs\praktikum-laravel
3. Pilih Replace jika Windows meminta konfirmasi.
4. app.css hanya berisi:
   @import "tailwindcss";
5. Jalankan:
   npm install
   npm run dev
6. Terminal kedua:
   php artisan serve
7. Buka http://127.0.0.1:8000
8. Setelah final, jalankan:
   npm run build

File controller, model, route, database, middleware, dan konfigurasi autentikasi tidak disertakan sehingga tidak ditimpa.
